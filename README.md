# Telegram AutoPost

Система сбора и публикации товарных сообщений из Telegram-источников. Объединяет альбомы и связанные сообщения в товар, извлекает поля и отправляет результат в настроенные каналы.

**Стек:** Python · aiogram · Telethon · PostgreSQL · SQLAlchemy · Alembic · Gemini OCR · Docker.

## Возможности

- Настройка источников, каналов, правил обработки, наценок и кнопок через `/admin`.
- Сбор альбомов, обработка поздних подписей и изменений сообщений.
- Строгие правила извлечения цены, размеров и количества; OCR для сложных случаев.
- Режимы AUTO/REVIEW, предпросмотр и последовательная публикация в каждый канал.
- Сохранение очереди и прогресса в PostgreSQL, миграции и восстановление после перезапуска.
- Фиксированные поля, альтернативный текст и код товара в запросах заказа/цены.

## Запуск

```bash
cp .env.example .env
# Заполнить собственные Telegram-доступы, администратора и параметры PostgreSQL.
docker compose up -d --build
```

Для сбора требуется собственная авторизованная Telegram-сессия. CLI установлен как `emoda`; доступные команды смотрите через `emoda --help`. Сессии, медиа, рабочая БД и клиентские данные исключены.

## Структура

`src/emoda/` — приложение; `alembic/` — миграции; `tests/` — существующие проверки. Интеграционные и live-проверки требуют отдельного окружения и доступов.
